How an agent pays (x402):
① Agent requests a protected endpoint → gateway returns HTTP 402 with a payment prompt
② Agent authorizes a micro USDC payment and signs it
③ Gateway verifies the on-chain receipt → releases the response
④ Every call leaves a verifiable trust receipt on-chain. No custody, no middleman.
