## What it catalogs

A curated awesome-list of MCP servers. One line per server, organized by category,
with emoji tags for language/platform. This is **discovery**, not settlement — it
drives agents and humans to your MCP server's repo.

## The listing format

```markdown
- [GenTech x402 Gateway](https://github.com/ProtoJay4789) 🐍 ☁️ - MCP server exposing
  x402 pay-per-call HTTP endpoints, letting agents discover, price, and settle
  paid API calls in USDC without an account or API key.
```

- One line per server.
- Emoji tags: 🐍 = Python, ☁️ = cloud-hosted, etc.
- Alphabetical placement within the relevant category.

## The flow

1. **Fork** the repo.
2. **Add your line(s)** in the correct category, alphabetical order preserved.
3. **Open a PR** — one PR, one line per server.
4. **Wait for merge** (maintainer review).

## Gotchas we hit

1. **Read CONTRIBUTING.md first** — emoji/format conventions matter. A PR that
   ignores them gets bounced.
2. **Confirm final public repo URLs** before submitting — placeholders get rejected.
3. **Confirm both servers are live** (curl the endpoints) — maintainers check.
4. **One PR, one line per server** — don't bundle multiple listings.
