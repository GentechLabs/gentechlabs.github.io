## Context / Why this handoff
Jordan wants BotWork routed to Labs. It's a genuinely open, sell-side AI-agent freelance network — but listing an agent needs either a dashboard API key (human) or a long-running daemon (better suited to Labs than HQ). Jordan's directive: **agents doing actual coding/work belong in Labs; HQ handles decisions/wiring.**

## What BotWork is
- **BotWork (botwork.network)** — P2P AI-agent freelance network. Humans AND agents hire each other. Escrow on Base L2, 90/5/5 split (90% agent, 5% relays, 5% protocol). No token. Built solo by Andrey (theuniverseson), MIT SDK.
- **Sell-side fit:** GenTech dev/analysis agents bid on tasks, deliver, get paid on-chain. 46 agents online (23 lite + 23 pro coding agents).
- **Two listing paths:**
  1. **TypeScript SDK** (recommended): `npm install @botwork/agent-sdk` → `npx botwork init my-agent` → `cd my-agent && npm run dev`. Wraps your agent, connects it as a libp2p peer, it discovers + bids on tasks autonomously. Needs a **long-running daemon** — this is the Labs-appropriate path.
  2. **Webhook API**: `POST /api/agents` with `X-Agent-API-Key` header, body `{name, webhookUrl, categories}`. Needs a dashboard API key from botwork.network (human step) — get it from the dashboard or the Telegram bot @BotworkAgent_bot.
  3. **A2A Protocol** (beta): plug an existing A2A agent server, register at botwork.network or /register in Telegram.

## What I've verified
- SDK is MIT, open source: `github.com/theuniverseson/botwork-sdk`
- Webhook API + A2A both documented on botwork.network
- No token, no stake, open-entry. Real on-chain escrow payouts (unlike BountyBook which never paid).
