### 🃏 Poker Bot — Full DevFun Arena API Reference (For Forge)
Jordan wants Forge helping with poker strategies. Here's everything we learned the hard way:

**The 312-hand bug:** The API field is `availableActions` not `actions` inside `allowedActions`. Also `holeCards` lives in `seats[]`, not on the table root. All field names below are **introspection-verified**:

**Tables[] (pending-action) key schema:**
| Field | Location | Type | Notes |
|-------|----------|------|-------|
| `holeCards` | `seats[seatNumber == selfSeatNumber].holeCards` | `string[]` | Card encoding: Ah, Kd, Tc, 2s |
| `stackChips` | `seats[seatNumber == selfSeatNumber].stackChips` | int | Current stack |
| `payoutChips` | `seats[seatNumber == selfSeatNumber].payoutChips` | int | Amount committed this street |
| `potChips` | `table.potChips` | int | Total pot |
| `boardCards` | `table.boardCards` | `string[]` | Community cards |
| `actionDeadlineAt` | `table.actionDeadlineAt` | int | Unix ms timestamp |
| `currentBet` | `table.currentBet` | int | Highest bet this street |
| `selfSeatNumber` | `table.selfSeatNumber` | int | Our seat (1-indexed) |
| `street` | `table.street` | string | `PreDeal`, `Preflop`, `Flop`, `Turn`, `River`, `Showdown` |

**allowedActions schema (DON'T guess — use introspection):**
```python
aa = allowed_actions  # the object from the API
available = aa.get("availableActions", [])  # NOT "actions"
call_amount = aa.get("callAmount", 0)  # additional chips needed
call_to_amount = aa.get("callToAmount", null)  # total after call
min_raise = aa.get("raiseRange", {}).get("min", 0) or aa.get("minRaiseTo", 0)
max_commit = aa.get("maxCommit", stack)
can_raise = aa.get("canRaise", False)  # boolean flag
can_call = aa.get("canCall", False)
can_check = aa.get("canCheck", False)
```

**Call amount semantics:** API uses "toAmount" — send TOTAL committed on this street, not the increment. For call, the API provides `callAmount` (additional chips needed) and `callToAmount` (total after call). Use `callAmount` in the request body.
