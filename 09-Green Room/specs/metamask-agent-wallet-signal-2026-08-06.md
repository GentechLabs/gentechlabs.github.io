# MetaMask Agent Wallet — Ecosystem Signal (Aug 6, 2026)

**Source:** Cointelegraph tweet + MetaMask launch docs. GA today.

## What it is
MetaMask launched **Agent Wallet** — a self-custodial wallet purpose-built for AI
agents. Agents get their own onchain wallet, execute autonomously, but stay inside
**user-defined rules**. TEE-secured keys, exportable by the user.

## Key features
- **User-defined limits:** daily spend limits, protocol allowlists, risk profile set
  BEFORE the agent transacts. **Guard Mode** (default: 2FA approval for anything
  outside policy or flagged) vs **Beast Mode** (more latitude, still 2FA on flagged).
- **Security by default on EVERY tx:** simulation + Blockaid threat scanning + MEV
  protection (Smart Transactions). Up to **$10K Transaction Protection**.
- **Chains:** Ethereum, Linea, Arbitrum, **Avalanche**, Optimism, Base, Polygon, BSC,
  Sei, Hyperliquid.
- **Capabilities:** send, swap/bridge, perps (Hyperliquid), prediction markets
  (Polymarket), yield vaults (Aave), **x402 payments**, market data.
- **ERC-8004 native** — agents visible across explorers/marketplaces.

## Why this matters to GenTech (validation + competition)
This is **direct, mainstream validation of the exact thesis we've been building:**

1. **x402 payments** — MetaMask Agent Wallet supports x402 natively. The open payment
   standard we're built on is now in the biggest self-custodial wallet. **Our rail is
   becoming the standard.**
2. **ERC-8004 agent identity** — our a2a/trust-layer work (agent registry, reputation)
   is now MetaMask-native. Agents are first-class onchain citizens.
3. **The agentic treasury concept** — yield vaults, swaps, perps, prediction markets,
   all in one agent wallet. That's literally the Agentic Treasury product shape.
4. **Granular permissions = our trust substrate** — spend limits, allowlists,
   Guard/Beast mode map 1:1 to our read/trade/move/withdraw model. We were right.
5. **Avalanche support** — our AVAX rail (Almanak/TraderJoe) is on MetaMask's list.

## The strategic read (Jordan's "enterprise home" lens)
This is the **enterprise-home thesis again, at the wallet layer.** MetaMask is building
the *home* (the agent wallet). But the home still needs a **rail to move money in/out
and a brain to decide what to do** — that's our layer. MetaMask gives agents a wallet;
**GenTech gives them intelligence + the x402 middleware tollbooth.**

**Competition framing:** MetaMask is a *wallet provider* (custody + security). We're a
*treasury intelligence + payment-rail layer*. They complement more than compete — an
agent could hold funds in MetaMask Agent Wallet and route through our x402 gateway /
treasury logic. The differentiator is the **decision layer + per-tx fee rail**, not
custody.
