## Design Direction
- **Dark theme** (keep) — fits the infra/dev audience
- **Gradient header** (keep, tone down) — blue→purple, no shimmer
- **Cards** (keep) — consistent radius, hover effects
- **Typography** (keep) — Inter is perfect
- **Remove:** Shimmer animation, fake status dots, "V4" branding, AAE jargon
- **Add:** Sticky nav, real status indicators, resume download, project impact metrics

## Model Usage
- **K3** — Design direction, layout decisions, color system, responsive breakpoints
- **K2.7** — Review the HTML/CSS output for edge cases, accessibility, performance
- **Flash** — Generate the actual code once the design is locked
