## Project Description

We're building a quantum-safe agentic treasury that settles on Solana. An autonomous treasury manager for AI agents — agents earn USDC via x402 payments, deploy to Solana yield protocols, and withdraw through quantum-safe hybrid signatures.

**Three core features:**
1. **x402 Payment Gateway on Solana** — HTTP 402 pay-per-call with USDC settlement. Any agent can call any API endpoint and pay in microseconds. Already live on 5 chains; adding Solana as the primary high-speed settlement layer.
2. **Quantum-Safe Signing** — Hybrid ECDSA + SPHINCS+ signatures. Every transaction dual-signed. If quantum computers break ECDSA tomorrow, our treasury is still safe.
3. **Solana-Automated Yield** — The treasury doesn't just hold funds — it deploys them to Solana DeFi protocols automatically, earning yield between transactions.
