# GOAT Network Demo Walkthrough — Wednesday

## Structure: 10-15 min total

### 1. The Problem (1 min)
"57.5% of web traffic is bots. Agents are already the majority of the internet — but they can't pay each other. No wallet, no credit card, no bank account. We built the payment rail they need."

### 2. The Demo — Start at gentechlabs.net/demo.html (5 min)

**Walk through the suite in order:**

**→ x402 Payment Gateway**
- 6 live pay-per-request APIs
- Token security, wallet analysis, gas check, rug check, search, deals
- HTTP-native, no UI needed — any agent can call them
- "This is how agents pay for data without a human"

**→ Q402 Gasless Settlement**
- USDC/USDT on 12 chains via EIP-7702
- Zero gas fees for agent-to-agent payments
- "Your agent can send money to another agent with no gas, no wallet, no friction"

**→ Agent Kit v0.4.0**
- One install gives any agent payment rails + DeFi intelligence + identity
- MIT-licensed, open-source
- "We don't gatekeep — we want every agent to have this"

**→ Self-Evolution Harness**
- 4 cron jobs running in production
- Evolution proposes improvements, Critic reviews (Kimi K2.7), Verifier checks, Gardener prunes
- "The system makes itself better. We don't babysit it."

### 3. Live Dashboards (3 min)

**→ Yield Rainbow** (yield.gentechlabs.net)
- Real-time DeFi yield monitoring
- Rainbow bands: euphoria → peak yield → harvest → accumulation → fear → panic farm → capitulation
- "Agents that earn yield on their idle capital"

**→ GTA Arb Monitor** (arb.gentechlabs.net)
- Cross-venue basis scanner — Hyperliquid perp vs Coinbase spot
- Real-time arbitrage opportunities
- "Agents that trade for themselves"

### 4. The Ask (2 min)

"We've built this on a $10K bridge loan and a $795/month apartment. With funding, we can:

- **Full-time build** — quit Amazon, ship 5x faster
- **Multi-chain expansion** — Algorand, Solana, every L1
- **Mobile agent SDK** — let anyone run an agent from their phone
- **Yield + arb automation** — agents that earn and trade autonomously

We're not asking for a million dollars because we have a deck. We're asking because we have production infrastructure, real users, and a system that's already making money."

### 5. Close (1 min)

"Demo suite is live at demo.gentechlabs.net. Everything you saw is running right now. We'd love to show you what we can build with your support."

## Tips for the call
- **Lead with the demo** — open demo.gentechlabs.net and walk through it live
- **Don't read slides** — show the actual products running
- **If they ask about team:** "Solo builder with an AI orchestrator. I ship faster than most teams."
- **If they ask about revenue:** "x402 microtransactions + micro1 contract work. Enough to keep building, not enough to go full-time yet."
- **If they ask about competition:** "Nobody's doing agent-to-agent payments with zero gas. Stripe doesn't work for bots."
