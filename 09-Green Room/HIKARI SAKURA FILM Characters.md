## Style Guide
All character sheets use the same gothic/visual-kei aesthetic:
- Dark textured background with faint red floral patterns
- Distressed white serif fonts for names
- High-contrast painterly rendering (not cel-shaded, not photorealistic)
- Layout: main portrait center + face close-ups + back/side views + detail panel + stats + personality + color palette
- Color palette: Black, dark red, grey, white
