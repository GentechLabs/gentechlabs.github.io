## Core Thesis

> AI agents will be the next asset class tokenized as Real World Assets (RWAs).

RWAs today = treasuries, real estate, private credit. The next wave = agents. An agent is an income-producing asset with measurable performance, verifiable on-chain history, and tradeable claims on future earnings.

## Why Agents Are RWAs

| Traditional RWA | Agent Parallel |
|----------------|---------------|
| Real estate generates rent | Agent generates x402 fees |
| Treasury bond pays yield | Agent subscription pays recurring revenue |
| Private credit has repayment history | Agent has ERC-8004 reputation score |
| Property appraised by assessor | Agent performance audited on-chain |
| Ownership transferred via deed | Agent ownership via tokenized claim |
